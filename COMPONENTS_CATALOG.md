# Component & Repository Structure Catalog

> Generated from the `main` branch of this repository. This is an inventory and organization guide; files have not been moved, renamed, or rewritten. Preserve existing import paths until a migration is planned and validated.

- **Repository:** [altetsa/ShadCN](https://github.com/altetsa/ShadCN)
- **Default branch reviewed:** `main`
- **Tracked file entries in tree:** 829

## Recommended organization principles

1. Keep reusable primitives in `components/ui/` and Base UI implementations in `components/base-ui/`; do not mix implementations that use different underlying primitives.
2. Keep product/application-level compositions (admin, AI, text effects, Aceternity, Kibo UI) grouped by domain under `components/`.
3. Keep complete page sections and templates in `blocks/`; group by purpose rather than renaming numbered variants until their usage and imports are checked.
4. Keep hooks, shared utilities, theme tokens, docs, registry metadata, scripts, and Storybook configuration separate from UI components.
5. Avoid moving files in bulk before checking import aliases, registry paths, Storybook stories, generated manifests, and external consumer paths.
